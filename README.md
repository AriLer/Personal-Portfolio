# Personal Portfolio Website

A personal portfolio website showcasing software projects, technical background, and personal endeavors. Designed with a modern, responsive interface for clean navigation across all devices.

---

## Features

* **Project Showcase:** Highlights featured open-source tools, technical projects, and capstones with direct links to live demos and repositories.
* **Responsive Layout:** Optimized for desktop, tablet, and mobile viewing.
* **Background & Technical Skills:** Summarizes technical background, core competencies, and project experience.
* **Contact & Links:** Quick access to professional profiles and channels.

---

## Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript, React
* **Hosting/Deployment:** Netlify
